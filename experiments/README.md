# Experiment Blocks

The repository is organized into three user-facing experiment areas:

- `comparison/`
  Four-method comparison, grid search, top-parameter verification, and full pipelines.
- `hyperparameter_analysis/`
  Sensitivity analysis for paper hyper-parameters and its plotting utilities.
- `sampling_bias/`
  Sampling-bias validation plotting utilities.

Legacy `tools/` commands still work, but the recommended entrypoints are under `experiments/`.
